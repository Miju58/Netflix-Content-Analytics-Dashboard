# Netflix Content Analytics Dashboard

## Project Overview

This Power BI dashboard analyzes Netflix content and provides insights into content distribution, growth trends, catagory, ratings, and geographic availability.

The dashboard is divided into two interactive pages:

1. Executive Overview
2. Content & Geographic Analysis

---

## Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization

---

# Page 1: Executive Overview

This page provides a high-level summary of Netflix content.

### KPIs

- Total Titles
- Movies
- TV Shows
- Countries
- Average Duration

### Visualizations

- Content Distribution by Type (Movies vs TV Shows)
- Total Titles by Country
- Total Titles by Year
- Interactive Filters (Year, Category, Rating)

### Key Insights

- Movies account for the majority of Netflix content.
- The United States has the largest content library.
- Netflix content grew rapidly after 2015.


---

# Page 2: Content & Geographic Analysis

This page focuses on content ratings and global distribution.

### Visualizations

- Global Content Distribution Map
- Total Titles by Rating
- Category-wise Content Analysis

### Key Insights

- TV-PG is one of the most common content ratings.
- Netflix content is distributed across multiple countries worldwide.
- Drama-related genres are among the most popular categories.

## Dashboard Features

- Interactive Slicers
- Cross-Filtering
- Netflix-Themed UI
- Page Navigation Buttons
- Responsive Dashboard Design

---
## Dataset

Source: Netflix Movies and TV Shows Dataset (Kaggle)

The dataset contains information about movies and TV shows available on Netflix, including title, country, rating, release year, duration, and category.
